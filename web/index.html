What Coven records and what it changes

Coven records tool calls after they happen: intent, programs, exit codes, file paths and sizes; never output, file contents or command arguments.

This page and the cloud change nothing in your repository. Your hosts do: they build each task on a coven/ branch, tick tasks.md, and with --auto-merge merge and push what every reviewer passed.
